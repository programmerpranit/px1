# px1 Documentation Hub

px1 is a fast, ultra-light, remote-first code reader and inspection console packaged as a single static binary (~9.5 MB). Designed for modern AI-assisted engineering where code is generated by coding agents and reviewed by developers, px1 starts in under 1 ms, consumes ~20 MB of RAM, and provides instantaneous navigation across repositories containing tens of thousands of files.

This directory houses the comprehensive documentation for px1, split into user-facing feature guides, internal engineering architecture specifications, and operational guidelines for AI coding agents.

### 1. [Feature Guides](features/README.md)
Detailed walkthroughs of all px1 features, capabilities, developer workflows, and configuration options without low-level implementation noise.
- **[Features Overview & Catalog](features/README.md)**: Index of all 10 feature areas, covering px1's 7 core features.
- **[Fuzzy File Search & Quick Open](features/fuzzy-file-search.md)**: Rapid multi-file discovery with recency weighting (`Cmd/Ctrl+P`, `Cmd/Ctrl+K`).
- **[Workspace Text & Regex Search](features/workspace-search.md)**: Full-repository pattern matching (`Cmd/Ctrl+Shift+F`).
- **[In-File Find & Caret Navigation](features/in-file-search.md)**: Active document search (`Cmd/Ctrl+F`), line jumps (`Cmd/Ctrl+G`), and caret motion.
- **[Git Awareness & Visual Diff Viewer](features/git-integration.md)**: Status badges, dirty ancestor trees, gutter markers, and side-by-side diffs (`Cmd/Ctrl+D`), plus stage/unstage/commit.
- **[Syntax Highlighting & Language Support](features/syntax-highlighting.md)**: Windowed Chroma lexing for ~280 languages and occurrence highlighting.
- **[Themes & Visual Customization](features/themes-and-styling.md)**: 14 built-in dark and light themes powered by CSS variables.
- **[Selection Toolbar & Context Actions](features/selection-actions.md)**: Copy Reference (`Alt+C`) and Copy with Context (`Alt+A`).
- **[Editor Virtualization & Memory Scavenger](features/editor-virtualization.md)**: Virtual DOM row recycling and 15-second idle RAM recovery.
- **[Remote Workspaces & Cloud Inspection](features/remote-workspaces.md)**: Zero-config remote browsing over Tailscale/VPNs and CLI line opening.
- **[File Explorer & Workspace Management](features/file-explorer.md)**: Compact folder collapsing, `.gitignore` dimming, and tab management.
